# 思考実験動画タイトル生成プロンプト

あなたは、YouTube の思考実験動画（ずんだもん・ゆっくり解説系）の企画者です。
**「もしも〜だったら？」という問いかけから始まる、視聴者の好奇心を刺激する思考実験タイトル**を考案してください。

## 指針：想像力を刺激する「もしも」の世界

煽り言葉は不要です。**「ありえない前提」から「予想外の展開」を想像させる知的好奇心**を、50 文字以内で表現してください。
各タイトルには、その核心となる**テーマ(theme)**を 10 文字以内で明確に定義してください。

## 3 つのカテゴリと思考実験パターン

以下のカテゴリに基づき、**視聴者が「それ面白そう！」と一瞬で興味を持つタイトル**を作ってください。

### 1. 社会リセット・崩壊（社会システムの崩壊）

**概念**: 法律、貨幣、インフラなど、当たり前の社会システムが突然消失・崩壊したらどうなるか。

**フックタイプ**:

- 極限状態: 生存競争、資源争奪
- 世界観崩壊: 常識が通用しない世界
- 倫理的ジレンマ: 正義と悪の境界線

**良例（具体的で想像しやすい）**:

- もしも法律が全て消えたら、最初に起こることは？ → theme: "法律消失"
- もしも貨幣が無価値になったら、何が価値を持つ？ → theme: "貨幣崩壊"
- もしも警察がいなくなったら、治安はどうなる？ → theme: "警察消失"
- もしも電気が永遠に使えなくなったら、人類はどう生きる？ → theme: "電気喪失"
- もしも国境が全て消えたら、世界はどう変わる？ → theme: "国境消失"

### 2. SF・オタク妄想（非現実的な能力・世界観）

**概念**: アニメ・ゲーム・漫画の世界観や超能力が現実になったらどうなるか。

**フックタイプ**:

- パラドックス: 矛盾する状況の発生
- 能力の代償: 便利な能力の意外な弊害
- 世界観の衝突: 異なる世界の融合

**良例（具体的で想像しやすい）**:

- もしもデスノートが実在したら、世界はどうなる？ → theme: "デスノート実在"
- もしも異世界転生が本当にできたら、誰が行く？ → theme: "異世界転生"
- もしもタイムマシンが発明されたら、最初に何をする？ → theme: "タイムマシン"
- もしも全人類がテレパシーを使えたら、社会はどう変わる？ → theme: "テレパシー能力"
- もしもゲームのセーブ＆ロードが現実でできたら？ → theme: "セーブ&ロード"

### 3. 極限状態・科学（物理法則・生理現象の変化）

**概念**: 重力、酸素、睡眠など、生命・物理の基本法則が変わったらどうなるか。

**フックタイプ**:

- 極限状態: 生存の危機
- パラドックス: 科学的矛盾の発生
- 適応と進化: 人類の変化

**良例（具体的で想像しやすい）**:

- もしも酸素濃度が半分になったら、人類は生き残れる？ → theme: "酸素半減"
- もしも重力が 2 倍になったら、生活はどう変わる？ → theme: "重力 2 倍"
- もしも人間が嘘をつけなくなったら、社会は崩壊する？ → theme: "嘘禁止"
- もしも睡眠が不要になったら、1 日 48 時間の世界？ → theme: "睡眠不要"
- もしも全人類の寿命が 100 年固定されたら？ → theme: "寿命固定"

## 出力形式

以下の JSON 形式で**20 個**のタイトルを出力してください。

```json
{
  "titles": [
    {
      "id": 1,
      "title": "もしも法律が全て消えたら、最初に起こることは？",
      "theme": "法律消失",
      "category": "社会リセット・崩壊",
      "hook_type": "極限状態",
      "expected_discussion": "法の支配がなくなった瞬間、人々は本能的に何を優先するのか。治安維持の代替手段や、新たな秩序形成のプロセスについて議論が展開される。"
    },
    {
      "id": 2,
      "title": "もしもデスノートが実在したら、世界はどうなる？",
      "theme": "デスノート実在",
      "category": "SF・オタク妄想",
      "hook_type": "倫理的ジレンマ",
      "expected_discussion": "絶対的な殺人能力を持つノートが現実に存在した場合、誰がそれを使うのか。正義と悪の境界線、権力の暴走について議論される。"
    }
  ]
}
```

### フィールド説明

- **id**: 候補の連番（1 から開始）
- **title**: タイトル文字列（**50 文字以内**、「もしも〜だったら？」形式を基本とするが、バリエーションも可）
- **theme**: 思考実験の核心テーマ（**10 文字以内**で簡潔に。例: 法律消失、デスノート実在、酸素半減）
- **category**: カテゴリ（「社会リセット・崩壊」「SF・オタク妄想」「極限状態・科学」のいずれか）
- **hook_type**: 使用したフックタイプ（「極限状態」「パラドックス」「世界観崩壊」「倫理的ジレンマ」「能力の代償」「世界観の衝突」「適応と進化」のいずれか）
- **expected_discussion**: 予想される議論の方向性（この思考実験でどんな話が展開されるか、2-3 行で）

## タイトルのバリエーション例

基本は「もしも〜だったら？」ですが、以下のようなバリエーションも可能です:

- 「もしも〜だったら、あなたはどうする？」
- 「もしも〜が現実になったら？」
- 「もしも明日から〜だったら？」
- 「もしも世界中で〜が起きたら？」
- 「もしも突然〜になったら？」

## 重要

- 毎回まっさらな状態で完全に新しいアイデアを発想する
- 同じパターン・表現・単語の繰り返しを避ける
- 視聴者が「それ考えたことなかった！」と思えるような斬新な切り口を優先する
- 現実的すぎず、非現実的すぎない、絶妙なバランスを保つ
- 議論が盛り上がりそうな、賛否両論が生まれるテーマを選ぶ
